# 错误处理

本文说明失败、阻塞、重试和人工介入规则。

## 失败

失败表示动作已执行但未达到验收标准。失败必须记录：

- 失败阶段。
- 失败原因。
- 证据引用。
- 是否可重试。

## 阻塞

阻塞表示当前角色无法继续推进。阻塞必须记录：

- 阻塞原因。
- 缺失依赖。
- 已尝试动作。
- 下一步建议。

## 重试

重试必须创建新的 `attempt_id`，不得覆盖旧记录。

## 人工介入

连续失败或权限不足时，应升级人工介入。人工介入不是绕过流程，而是记录决策和确认依据。

## Fail Closed

校验失败、状态非法或权限不明时，默认停止推进并记录 `blocked`。
