# 可观测性

本文说明进度、证据和报告规则。

## 进度事件

每个角色在关键节点写入 `progress.jsonl`：

- 接收任务。
- 开始阶段。
- 完成关键动作。
- 失败。
- 阻塞。
- 重试。
- 退出。

## 证据引用

事件应引用证据，而不是塞入大段原始日志。

可引用：

- 文件路径。
- 命令摘要。
- result 文件。
- closeout 文件。
- report 文件。
- 上游事件。

## 逐级汇总

子级事件由直属父级汇总，再向上汇报。pm 不直接消费后代原始噪声日志。

## 报告

summarize 命令应生成面向用户的 run 摘要，包含状态、结果、风险和下一步。
