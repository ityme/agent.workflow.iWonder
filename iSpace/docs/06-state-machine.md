# 状态机

本文说明状态转移规则。

## 基本原则

- 状态必须显式转移。
- 非法跳转必须 fail closed。
- 阻塞必须记录证据。
- 重试必须保留原始失败事件。
- 每次跨角色交接必须有上游事件和下游确认。

## 默认状态

常用状态包括：

- `intake`
- `clarifying`
- `planned`
- `running`
- `waiting_ack`
- `passed`
- `failed`
- `blocked`
- `exited`

## 阻塞判断

满足以下条件之一才可停止等待：

- 子级明确返回失败。
- 子级明确返回阻塞。
- 连续 3 次无进展检查，并存在阻塞证据。
- 状态机非法跳转。
- 权限缺失或依赖不可用。

## 校验目标

validate 命令应检查：

- 当前状态是否合法。
- 下一状态是否允许。
- `reply_to` 是否引用存在事件。
- `event_id` 是否重复。
