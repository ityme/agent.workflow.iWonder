# 接入检查清单

- [ ] 已确认 Python 3 可用。
- [ ] 已阅读 `README.md`、`docs/01-quickstart.md` 和 `docs/14-security.md`。
- [ ] 已选择默认 profile 或新建项目 profile。
- [ ] 已确认 adapter command 全部使用数组形式。
- [ ] 已确认 allowlist 只包含需要执行的命令。
- [ ] 已确认外部发布、合并、部署和远端写入默认禁用。
- [ ] 已运行 `python iSpace/tools/harness.py demo`。
- [ ] 已运行 `validate`、`audit`、`summarize`。
- [ ] 已确认 `track/tmp/reports` 是 harness 核心工具的默认写入范围。
